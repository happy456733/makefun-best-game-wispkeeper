Wispkeeper — Light the Hollow. A lantern-runner arcade game: guide a little wisp through five darkening zones of the Hollow, where your light is your life. Gather light shards to stay alive, chain combos, dodge the shades and thorns, spend flares to burn the dark back, open each zone's gate, and carry the last light home to the Dawn Gate. Keyboard (WASD/arrows + Space) or mouse — no build step, no network, just static files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or serve `game/` from any static server and open `index.html`.
